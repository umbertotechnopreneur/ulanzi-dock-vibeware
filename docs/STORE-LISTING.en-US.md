# UlanziDeck — English Store listing

## Description

Your shortcuts, music and favorite apps, one button away.

UlanziDeck turns your Ulanzi D200H into a personal shortcut controller for Windows.
Launch apps, control media and use keyboard shortcuts from the dock's buttons.

I built UlanziDeck for my own desk. It includes ten pages: Windows / media,
Utility, Codex, VS Code, Spotify, Word, PowerPoint, Excel, OBS Creator and Themes.

Choose whether pages follow the app you are using or switch them manually.
Enable the pages you need, dim unavailable actions and customize shortcuts
through local settings files.

All 13 themes are included. No theme purchase or subscription is required.

Built in Rust, with native Windows x64 and ARM64 packages. No vendor software
or custom driver is required.

Requires a Ulanzi D200H, sold separately. This is the model I own and use;
other models are unverified. App-specific shortcuts require the corresponding
applications. The OBS Creator page requires matching hotkeys in OBS.

Created by Umberto Giacobbi as a weekend project, with AI assistance, as part of
my VibeWare initiative. Source code is available under the MIT License.

UlanziDeck is an independent, unofficial project. It is not affiliated with,
sponsored by or endorsed by Ulanzi. All trademarks belong to their respective owners.

## Product features — one field per line

- Ten pages for everyday shortcuts, media controls and popular applications
- All 13 visual themes included, with no theme purchase required
- Optional automatic page switching based on the active application
- Enable or disable application pages without losing your shortcuts
- Customizable keyboard shortcuts and application mappings through local settings files
- Button artwork for both pressed and released states
- Brightness controls and a wide display for the clock or page status
- Windows tray controls and optional startup at sign-in
- Native Windows x64 and ARM64 packages
- Works with the Ulanzi D200H without vendor software or a custom driver
