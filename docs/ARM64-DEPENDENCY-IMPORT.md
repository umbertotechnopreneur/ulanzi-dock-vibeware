# Windows ARM64 dependencies

The locked Windows ARM64 dependencies include these versions of Microsoft's
`windows_aarch64_msvc` crate. Use `Cargo.lock` to check the versions and checksums.

| Version | Official download |
| --- | --- |
| 0.48.5 | https://static.crates.io/crates/windows_aarch64_msvc/windows_aarch64_msvc-0.48.5.crate |
| 0.52.6 | https://static.crates.io/crates/windows_aarch64_msvc/windows_aarch64_msvc-0.52.6.crate |
| 0.53.1 | https://static.crates.io/crates/windows_aarch64_msvc/windows_aarch64_msvc-0.53.1.crate |

For a new import, follow the [first-import steps](DEVELOPMENT.md#prepare-new-dependencies)
before using the archives or extracted files. The build uses the prepared Cargo
cache offline.
