# Windows UI design references

I am exploring a Windows-only WinUI 3 editor while keeping the Rust controller and CLI portable.

The [WinUI 3 concepts v1](winui3-concepts-v1/README.md) include twelve original PNG mockups: Key editor, Pages, Applications, Themes, Presets and Device, each in dark and light appearance.

- [Browse the offline comparison gallery](winui3-concepts-v1/index.html).
- [Read the implementation brief](winui3-concepts-v1/SPECIFICATION.md), including Hue/Saturation controls.
- [Read the image-generation prompt set](winui3-concepts-v1/prompts.md).
- [Download the complete ZIP](ulanzi-winui3-concepts-v1.zip).

These are design references, not an implemented WinUI front end or live hardware captures. Existing interfaces and device behavior retain their own verification status.
